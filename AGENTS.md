# AGENTS.md — Память проекта Metrolog_Manage

## Реализованный функционал

- [x] Учёт средств измерений (СИ) — CRUD
- [x] Контроль сроков поверок (расчёт следующей даты по МПИ)
- [x] Управление выдачей/возвратом приборов (складской учёт)
- [x] Справочники: персонал, отделы, склады
- [x] Генерация этикеток с DataMatrix-кодами (bwip-js)
- [x] Система уведомлений (контекст + хуки)
- [x] Конструкторы категорий и фильтров для СИ
- [x] Графики на Recharts
- [x] Статус "На поверке" для СИ
- [x] **Рабочее место поверителя** — модуль внесения результатов поверки
  - Создание протоколов поверки с снапшотом данных СИ
  - Авторасчёт погрешности и вердикта по точкам
  - Жизненный цикл СИ: автоматическая смена статуса при начале/завершении поверки
  - Пересчёт nextVerificationDate при успешной поверке
  - Уведомления при отрицательном результате
  - Журналирование операций через OperationLog
  - Влияющие величины (температура, влажность)
  - Read-only для завершённых/отклонённых протоколов
  - Unit-тесты (расчёт погрешности, вердикт, epsilon, жизненный цикл, неизменяемость)
